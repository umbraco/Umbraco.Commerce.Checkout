# Upgrade to Umbraco 19

From Umbraco CMS `[18.0.0, 18.999.999)` / Umbraco Commerce `[18.0.0, 18.999.999)` to CMS `19.0.0-beta1` (tag `release-19.0.0-beta1`) / Commerce `19.0.0-beta.1`.
Branch `topic/19.x/cms-19-upgrade` → PR into `release/19.0.0`, cut from `main` (`147b219`).

**Targets CMS release:** `release-19.0.0-beta1`. The package's own version is `19.0.0-beta.1`.

The full CMS breaking-change inventory for 19.0.0-beta1 was done for Commerce Core (Core repo, `docs/upgrades/v19.md`). This file lists what hits Checkout, checked against that list, a v18 and a v19 build (CS0618), and `@typescript-eslint/no-deprecated` on the v19 typings.

## Decisions

- Keep the upgrade to what v19 forces (maintainer, 30-10-2026). Checkout ↔ Customer feature gaps are raised as separate issues for a 19.x minor: hard-coded address aliases vs `OrderPropertyConfig`, marketing opt-in not mapped to customer communication preferences, customer telephone not synced, saved-address picker for returning members.
